# Tokens — Streak screen

Екран не має жодного захардкоженого кольору: усе на змінних DS
(колекція `Color/Semantic`, моди Light / Dark). Hex нижче — резолвнуті значення
**для звірки**, у коді читати з теми.

| Токен | Light | Dark | Де використано |
|---|---|---|---|
| `bg/default` | `#f9fafd` | `#0c0d11` | фон екрана, вінʼєтка |
| `text/default` | `#0c0d11` | `#f9fafd` | число, заголовок похвали, підпис дня в серії |
| `text/secondary` | `#4f5059` | `#c2c3cb` | `DAY STREAK`, другий рядок, майбутні дні |
| `border/strong` | `#dddee4` | `#4f5059` | кільце порожнього дня |
| `bg/warning-bold` | `#ffcc00` | `#ffcc00` | купол, глоу вогника, іскри, трек серії, флери |
| `Colors/Yellow/500` | `#ffd429` | `#ffd429` | верхній стоп золотого градієнта числа й `DAY STREAK` |
| _#f5735c_ (примітив) | `#f5735c` | `#f5735c` | нижній стоп того ж градієнта |
| `border/brand-subtle` | `#ebedff` | `#393292` | холодна підошва під вогником |
| `bg/default-0` | прозорий | прозорий | далекий стоп градієнтів |

## Прозорості

Усі — з колекції `Opacity`, ніяких «на око»:

| Шар | Токен |
|---|---|
| Купол | `opacity/30` (у біті +20 програмно) |
| Глоу вогника | `opacity/30` |
| Підошва | `opacity/40` |
| Halo (розмита копія) | `opacity/10` |
| Боке | `opacity/10` |
| Вінʼєтка | `opacity/50` |
| Трек серії — заливка | `opacity/10` |
| Трек серії — свічіння | `opacity/30` |

## Відступи й радіуси

`space/*` і `radius/*` з DS. Ритм нижнього блоку: **32** між блоками,
**16** усередині хедлайна, **4 / 2** усередині пар. Правило: чим глибше
вкладення — тим менший гап.

## Типографіка

| Роль | Стиль DS |
|---|---|
| Число | `Display/XLarge/Bold` (56/64), заливка — золотий градієнт ЗГОРИ ВНИЗ |
| `DAY STREAK` | `Body/Small/Medium` (12/18) + трекінг 8%, той самий градієнт |
| Заголовок похвали | `Body/Large/Semibold` (16/24) |
| Другий рядок | `Body/Medium/Regular` (14/21) |
| Підписи днів | `Body/Medium/Medium` (14/21), активні — Semibold |
| Кнопка | `Body/Large/Semibold` |

## Дірки в DS, які цей екран підсвітив

1. **`Display/XLarge` 56 px — стеля типографіки.** Для мілстоун-числа мало;
   в Opal нумерал приблизно вдвічі більший. Потрібен hero-тір.
2. **Трекінг для капсу.** `DAY STREAK` набраний з `letterSpacing: 8%` руками —
   у DS немає стилю для all-caps лейблів.
3. **`_Day / Month` без осі State.** Майбутні дні не притишити пропом,
   у макеті це оверрайд `text/secondary`. Просить вісь `Default · Future`,
   як у `_Day / Week`.
4. **Немає share-іконки.** Кнопку шеру з екрана прибрали, але питання лишилось.
5. **`Opacity` без модів.** Тому інтенсивність світла однакова в обох темах;
   на світлій розфокус доводиться вимикати вручну.
6. **Золотий градієнт на ПРИМІТИВАХ.** Стопи взяті з `Colors/Yellow/500` і `#f5735c`, бо семантичного теплого градієнта в DS немає, а нові змінні не заводимо. Ціна: число й лейбл НЕ перевертаються по темі — золото однакове в Dark і Light. На світлій це дає контраст на межі AA для капсу 12px; якщо знадобиться запас — лейбл вести на `text/default`, градієнт лишити числу.
7. **Підошва на `border/brand-subtle`.** Border-токен у ролі світла — свідомий
   компроміс замість нового токена (домовленість не заводити нові змінні).
   Той самий прийом, що з `border/danger` у треку серії.
